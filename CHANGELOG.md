# Changelog

## 0.1.0

- Switch Claude Code, Codex and Antigravity accounts from the menu bar or system tray, with verification and automatic rollback.
- Live usage from Anthropic, OpenAI and the running Antigravity app, with 5-hour and weekly limits per account.
- Saved sign-ins encrypted with AES-256-GCM, with the key kept in the system credential store.
- Passphrase-protected backups, activity history and crash recovery.
